# John Mugita — Portfolio

A minimalist, image-led personal portfolio and journal built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — homepage
- `projects.html` — project archive
- `journal.html` — blog / journal
- `about.html` — profile
- `contact.html` — contact page
- `styles.css` — responsive visual system
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to finish publishing. The site address is https://johnlumbasi13.github.io.

## Before sharing publicly
- Replace all illustrative Unsplash images with photographs you own or have permission to publish.
- Add only project information you are authorised to disclose.
- Confirm each case study accurately describes your personal role and separates it from the wider project team's work.
- Remove faces, vehicle registration plates, private drawings, security details and confidential client information where necessary.
- Add a professional contact method only after reviewing privacy implications.

The current project and journal entries are placeholders / draft topics, not claims of completed work or published articles.
